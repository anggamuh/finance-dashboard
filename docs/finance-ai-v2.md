# Finance AI V2 — Markdown, dashboard insights, chart and account drilldown

## What's included

- Safe CommonMark rendering for assistant replies: raw HTML stripped and unsafe links blocked. Raw user prompts still Blade-escaped.
- Chart of six months of operational-expense totals computed from the existing Accurate transaction filter (not generated by Gemini).
- Monthly comparison cards and deterministic insights, including largest account-level increase based on current and previous month.
- Account detail: click an expense account in the sidebar to show server-paginated transactions within the selected month. Raw transaction descriptions are displayed inside Laravel only, **not** included in prompts sent to Gemini.
- Follow-up support already in V1: last 6 message turns are provided to Gemini. Switching month now clears history, preventing cross-period confusion.
- Extra quick question asks about reasons for expense changes, with caution not to fabricate business causes.

## Deploy

1. Review and merge the PR.
2. On Hostinger SSH: `git status` then `git pull --ff-only origin main`.
3. `php artisan view:clear` and `php artisan config:clear` if supported.
4. Go to Finance AI. Select September 2026 and ask about the biggest three expense accounts. Check bold/table rendering, chart, and click the top account to inspect transactions.
5. Switch to October: messages should clear and chart/account data should change.

## Limitations and security

- V2 does not introduce AI-created database mutations or natural-language SQL execution.
- Drilldown is for accounts appearing in the top eight by expense value. The selected account, date and expense category restrictions are always validated through the server query.
- App still follows its existing authenticated access policy for the underlying finance transactions. Organizations with separate roles should introduce explicit role permissions before granting other users Finance AI.
- Explanations of *why* a cost changed are only as strong as the recorded data; code presents quantitative contributors, not invented business causes.
- No new Composer/NPM packages or migrations. Tests: `php artisan test --filter=FinanceAiInsightsTest` in local or CI (not production).
- The Gemini model remains configured by server-only `GEMINI_MODEL`; this PR does not touch secrets or free-tier settings.
